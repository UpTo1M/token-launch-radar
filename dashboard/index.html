The market’s own yardstick

Peer multiples are not guessed: each category’s multiple is the median market-cap-to-TVL ratio of the tokenized protocols in that category in this same snapshot. The biggest tokenized protocols set the scale:

How the value is scored

implied = TVL × peer multiple × growth factor × tenure factor × chains factor
  • Peer multiple — median mcap/TVL of tokenized protocols in the same category, used only where at least three tokenized peers set it; thinner categories use the global median —×, so one outlier peer cannot set a category. Clamped to 0.05–1.50×.
  • Growth factor — 1 + 0.6 × 7-day TVL change, change clamped to −50%..+100%.
  • Tenure factor — 0.85 + 0.30 × min(age, 4y) / 4y; a long track record with no token yet scores up to 1.15×, a new listing 0.85×, unknown listing date 1.00×.
  • Chains factor — 1 + 0.03 per extra chain, up to five (+15%).

Read it honestly: “records no token” is what DefiLlama’s record says, not proof a token does not exist, and the implied value is this radar’s own claim — it does not predict whether or when any protocol issues a token.
